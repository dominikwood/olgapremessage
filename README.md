# Olga Prem: сайт курса

Одностраничный сайт на украинском и русском языках. Утверждённый дизайн сохранён. Карусели, увеличение отзывов, локальные видео и Telegram-контакт работают без стороннего фронтенд-фреймворка.

## Запуск и проверка

Требуется Node.js 24.x.

```powershell
npm ci
npm test
npm run build
npm start
```

Локальный адрес: http://localhost:3000. Сборка проверяет файлы, регистр путей и отсутствие очевидных секретов в публичном коде; она не перерисовывает сайт и не перекодирует медиа.

Для настоящей отправки заявок создайте локальный `.env` по `.env.example` и заполните `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`. Не публикуйте этот файл. Тесты используют имитацию Telegram и ничего не отправляют.

## Vercel

Полная пошаговая инструкция: [DEPLOY-VERCEL.md](DEPLOY-VERCEL.md).

- Framework: Other; Node.js: 24.x.
- Build Command: `npm run build`; Output Directory: `public`.
- `api/apply.js`: Vercel Function для формы; `lib/lead-handler.js`: общий обработчик для Vercel и локального сервера.
- `vercel.json`: настройки деплоя, HTTP-заголовки и редирект `/index.html` на `/`.
- `.vercelignore`: разрешает загрузку только нужных папок/файлов, исключая `.env`, QA и рабочие материалы.
- Переменные Telegram задаются в Vercel Environment Variables, а не в коде. Production-сборка остановится, если они отсутствуют или явно неверного формата.
- Домен для canonical, sitemap и robots: `https://olgraprem.org.ua/`.

Загружайте корень проекта, не только `public`: иначе не будет серверной функции. Постоянно запущенный `server.js` на Vercel не нужен; он оставлен для локальной разработки.

## Редактирование

- Разметка: `public/index.html`; стили: `public/styles.css`.
- Переводы и форма: `public/app.js`.
- Фото, иконки, шрифты, видео: `public/assets/`.
- Карусели: `public/certificates.js`; видеоотзывы: `public/reviews.js`.
- Футер и Telegram-ссылка: `public/footer-content.js`; подробнее: [FOOTER-GUIDE.md](FOOTER-GUIDE.md).

Токен бота хранится только на сервере. Имя `@aromaprem_bot` в футере и `TELEGRAM_CHAT_ID` — разные вещи: chat ID определяет получателя заявок, а ссылка в футере открывает беседу с ботом. Код сайта не реализует диалоги самого Telegram-бота.

Юридические страницы, отменённые ранее, не восстановлены. Техническая готовность к деплою не означает готовность юридических документов к публичному запуску.
